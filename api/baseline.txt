package validation // import "github.com/faustbrian/go-validation/v2"

Package validation provides typed, deterministic, bounded application validation
without transport, binding, or persistence dependencies. Build a Context and use
Validator/rules or an optional structplan; Report.Err is the complete success
predicate, not Empty or HasErrors alone. Value preserves missing/null/present
states without coercion, defaulting or input mutation. Generic input objects and
callback implementations are borrowed, not deep copied; purity and concurrent
safety remain application obligations. AsyncAll owns bounded per-call workers
and joins admitted callbacks, but cannot preempt noncooperative work. Transport,
IO policy and provider shutdown remain outside core; limits are selected
budgets, not total CPU/heap caps.

	MaxCollectionSize int
	// MaxStringLength caps checked input/catalog bytes before parsing or escaping; default 65536, not all escaped-output allocation.
	MaxStringLength int

	MaxViolations int
	// MaxPathLength caps human-rendered path bytes at report admission, default 1024; not total path construction or escaped-pointer bytes.
	MaxPathLength int
	// MaxMetadataEntries caps Context metadata and violation parameter entries, default 16.
	MaxMetadataEntries int
	// MaxMetadataKeyLength caps Context keys and machine diagnostic code/parameter names, default 64.
	MaxMetadataKeyLength int
	// MaxMetadataValueLength caps Context locale/operation/metadata and diagnostic parameter bytes, default 256; not confidentiality.
	MaxMetadataValueLength int
	// MaxRegexPatternLength caps Pattern constructor expression bytes, default 1024; not a caller-context timeout.
	MaxRegexPatternLength int
	// MaxCustomConcurrency caps AsyncAll workers per invocation, default 8; concurrent calls multiply the bound.
	MaxCustomConcurrency int
	// MaxStructFields caps typed definitions and total reflected fields visited during compilation, default 256.
	MaxStructFields int

	// MaxCompiledPlans caps distinct reflect.Type entries in an instance Cache, default 256; Clear permits later recompilation.
	MaxCompiledPlans int

}
    Report is an immutable, ordered, deduplicated collection of violations with

func AsyncAll[T any](ctx context.Context, validationContext Context, value T,
	validators ...AsyncValidator[T],
) Report
    AsyncAll executes context-aware validators with bounded concurrency and
    merges their reports in declaration order. Cancellation stops unscheduled
    work; validators already running remain responsible for honoring ctx.
    After checking caller cancellation, total supplied positions (including
    nil) must fit MaxCollectionSize before workers or result storage are
    allocated. Require a nonnil caller context. Bounds apply per invocation;
    concurrent calls multiply workers. Admission stops when the select observes
    caller cancellation, not by forcibly interrupting an accepted callback.
    Every admitted worker is joined; partial findings and hidden blocking state
    survive terminal/truncation merging. Child terminal reports do not cancel
    peers. The validator slice and generic input are borrowed throughout this
    call.

func ContextReport(validationContext Context, ctx context.Context) Report
    ContextReport returns an empty report that snapshots ctx.Err(). An active
    context produces no terminal state. Require a nonnil context; nil panics
    on direct use. Only exact standard cancellation/deadline identities are
    retained, never a request context or custom cancellation cause.

func NewReport(limits Limits) Report
    NewReport creates an empty report governed by the supplied limits without
    validating/defaulting them. Use Context.Limits or positive DefaultLimits;
    a zero Report can merge into a configured report but is not an admission
    constructor with default retention bounds.

func (r Report) Add(violation Violation) Report
    Add returns a copy-on-write report with a unique violation retained within
    limits. Diagnostic validation precedes display-path admission; refusal
    replaces input with fixed invalid_violation or rooted path_limit findings.
    Blocking state is recorded before dedup/retention, so dropped errors still
    block Err. Identity includes typed path/code/severity/sorted parameters, not
    cause identity; causes are borrowed interfaces and are never rendered here.

func (r Report) ContextError() error
    ContextError reports the captured context terminal identity, if any.

func (r Report) Empty() bool
    Empty reports whether no violations were retained, not complete success.
    A terminal or truncated report can be empty while Err is nonnil.

func (r Report) Err() error
    Err returns a typed error if validation did not complete or contains a
    blocking violation.

func (r Report) HasCode(code string) bool
    HasCode reports whether a retained violation has code.

func (r Report) HasErrors() bool
    HasErrors reports whether any blocking violation was observed, including one
    omitted because MaxViolations was reached.

func (r Report) Len() int
    Len returns the number of retained violations.

func (r Report) Merge(other Report) Report
    Merge appends other's retained violations under receiver limits, preserving
    hidden blocking/truncation flags. The receiver's first terminal wins. No
    dropped finding is reconstructed, so Len/HasCode can omit a blocking reason.

func (r Report) String() string
    String returns a cause/parameter-free summary. Active reports use failure-
    oriented prose even when empty or warnings only; it is not a success test.
    Use Err for acceptance and restrict explicit path/parameter/cause projection
    according to application confidentiality policy.

func (r Report) Truncated() bool
    Truncated reports whether a violation was omitted by the configured limit.

func (r Report) Violations() []Violation
    Violations returns a defensive copy preserving validation order.

type Validator[T any] interface {
	// Validate must return ordered findings without mutating borrowed input or
	// hiding IO. Determinism/purity are implementation obligations, not enforced
	// by Context. Instances reused concurrently must support that concurrency.
	// A Report may contain warnings, truncation or terminal state; use Err for
	// complete success. Arbitrary interface panics propagate on direct calls;
	// use IsolatePanics where containment is required.
	Validate(Context, T) Report
}
    Validator is the deterministic, side-effect-free validation contract.

func All[T any](mode Mode, validators ...Validator[T]) Validator[T]
    All requires every validator to pass. The supplied positions, including nil
    entries, must fit Context.Limits().MaxCollectionSize before any invocation.
    The supplied slice/input is borrowed across future calls. Empty/all-nil
    inputs pass; zero/unknown Mode collects all. An arbitrary nested panic is
    contained by the outer function adapter and can replace prior findings.

func Any[T any](mode Mode, validators ...Validator[T]) Validator[T]
    Any requires at least one validator to pass. Failed alternatives are
    returned only when every alternative fails. The supplied positions,
    including nil entries, must fit Context.Limits().MaxCollectionSize before
    any invocation. Empty/all-nil inputs also return nonblocking success.
    If any alternative passes, only successful alternatives' findings (including
    warnings) remain; a terminal alternative returns accumulated partial
    findings immediately. Caller-owned validator slices must stay stable across
    future calls.

func Dependent[T any](prerequisite, dependent Validator[T]) Validator[T]
    Dependent runs dependent only when prerequisite has no blocking errors.

func IsolatePanics[T any](validator Validator[T]) Validator[T]
    IsolatePanics explicitly wraps a custom validator with panic containment.
    The panic payload and rejected value are deliberately discarded.

func Not[T any](validator Validator[T]) Validator[T]
    Not passes only when validator fails.

func When[T any](predicate func(T) bool, then, otherwise Validator[T]) Validator[T]
    When chooses a validator using a deterministic typed predicate.

type ValidatorFunc[T any] func(Context, T) Report

func WriteProblem(writer http.ResponseWriter, problem Problem) error
    WriteProblem writes caller-owned problem data without routing or binding.
    Invalid status rejects before touching writer. For valid status it sets
    the content type and writes headers before encoding; failure can leave a
    partial response. Writer/encoder panics are not contained; encoder errors

    not a typed check.

type Validator[T any] interface {
	// Validate borrows caller context/input and must return cooperatively.
	// Instances reused concurrently must support it; direct interface panics

func Chain[T any](mode validation.Mode, validators ...Validator[T]) Validator[T]
    Chain evaluates service hooks in declaration order and preserves
    caller cancellation or deadline as a terminal validation outcome.
    Total supplied positions, including nil, must fit MaxCollectionSize before
    invocation; caller cancellation takes precedence over this admission.
    The validator slice is borrowed until future calls, not copied at creation.
    Unknown/zero Mode behaves as CollectAll. Chain owns no workers or shutdown;
    each direct provider must return before terminal state can be captured.
    A provider panic aborts this invocation through the Hook boundary and can
    replace already accumulated findings with the core panic report.

startup-compiled validate-tag plans. New/Add/Compile or CompileTags are
entry points; these plans validate without binding, coercion or provider IO.
